Custom FreeCell Solitaire Pro

An upgraded, highly customizable web version of the classic FreeCell Solitaire card game. Built with pure JavaScript, HTML5, and Tailwind CSS, this version introduces customizable game rules, customizable hidden card options, a single-step move undo, timer tracking, and a dynamic local leaderboard.

🌟 Key Features

Customizable Column Layouts (4 to 10 Columns):

Dynamically scale the game board. Adjust the standard 8-column layout down to 4 or up to 10 columns on the fly. Cards automatically redistribute based on the selected layout.

Targeted & Random Hidden Card Modes:

Row Hiding: Choose to start with the 1st, 2nd, or 3rd row dealt face-down for an extra tactical challenge.

Random Hiding: Specify a quantity of random cards across the board to remain hidden at the start of the deal.

Auto-Reveal: Hidden cards automatically flip face-up as soon as they become top/exposed cards.

Supermove Mechanics & Validation:

Automatically calculates maximum movable stack limits based on available open Free Cells and empty Tableau columns.

1-Step Undo & Timer Controls:

Single-step undo feature allows players to revert accidental moves.

Real-time game clock and move tracking.

Personalized Profiles & Configuration Leaderboard:

Players can enter a custom username.

Tracks completion times and move counts locally per configuration (e.g., 8Cols_Row1Hidden+3Random).

Filterable Hall of Fame scoreboard sorted by fastest completion time.

Responsive & Intuitive Interface:

Full Drag-and-Drop support alongside single-click auto-move logic.

Mobile-friendly design with dynamic card sizing.

🎮 How to Play

Objective: Move all 52 cards to the four Foundation piles, organized by suit from Ace to King.

Tableau: Build stacks down in alternating colors (e.g., a red 7 on a black 8).

Free Cells: Use the four holding slots as temporary space for single cards.

Hidden Cards: Any card covered by a face-down card will reveal itself as soon as the top card is moved away.
